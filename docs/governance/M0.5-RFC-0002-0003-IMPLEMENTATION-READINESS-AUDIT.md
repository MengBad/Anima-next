## 5. Ordered implementation prerequisites (dependency order; facts, not a voted sequence)

- **P1. M0.4.x readiness gate passed.** Fact: Approval snapshot gates implementation on M0.4.x readiness (capability routing per M0.4.7 CLOSED / M0.4.8 pilot). Until green, no implementation begins.
- **P2. Planning wiring path resolved.** Fact: `constitution.Plan` + `derive_plan` exist but are not referenced by runtime. Implementation requires a decided wiring path connecting `constitution.Plan` to the live agent (replacing or adapting `TaskPlanner`). The contract does not specify the wiring; this is a precondition gap, not a contract change.
- **P3. Plan lifecycle field + Planning Interface operations exist.** Fact: `Plan` lacks a lifecycle field; `activate_plan`/`revise_plan`/`invalidate_plan` do not exist. These must exist for Plan to be governable per RFC-0002.
- **P4. Execution (RFC-0107) emits per-task outcomes.** Fact: Workflow `report_task_outcome` consumes `ExecutionResult`/`TaskOutcome`. If Execution cannot produce them, Workflow has nothing to report.
- **P5. Single Workflow Authority module exists.** Fact: run ownership is split across 3 systems. A single-writer Authority module must exist for the contract's single-writer rule (O1) to hold.
- **P6. Run-state model reconciled to RFC-0003 enum.** Fact: 3 divergent state sets exist. Implementation requires mapping them to pending/running/suspended/completed/failed/cancelled (or a defined migration).
- **P7. Workflow Interface operations exist.** Fact: start_run/suspend_run/resume_run/cancel_run/abort_run/report_task_outcome do not exist. Must exist on the Workflow Authority.

## 6. Summary answer

**What must exist before implementation can begin?**

1. M0.4.x readiness gate green (gating precondition from Approval).
2. A resolved wiring path for `constitution.Plan` into the runtime (currently unwired — gap).
3. Plan lifecycle + Planning Interface ops (currently missing — gap).
4. Execution able to emit per-task outcomes (RFC-0003 depends on it — gap if not ready).
5. A single Workflow Authority module (currently split — gap).
6. Reconciled run-state model to the RFC-0003 enum (currently 3 divergent — gap).
7. Workflow Interface ops implemented (currently missing — gap).

No contract redesign, no RFC amendment, no prioritization vote, and no implementation proposal is contained herein. This document is discovery-only.
