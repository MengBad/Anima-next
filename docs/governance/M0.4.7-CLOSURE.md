## Post-hoc Verification Note — 2026-09-18

> Appended by a later audit. **The text above is left verbatim**; this note only records what
> production was actually measured to be, read-only, on 2026-09-18.

The claim on line 84 (`capability_mode` never flipped to `True`) is accurate **for the M0.4.7
window and for the repository tree**, but it is **no longer true of the production deployment**.
Reading `/opt/anima/config.yaml` (the hand-maintained production file, which is **not under
version control**) shows four governance switches at `true`:

| Key | Code default | Production (2026-09-18, read-only) |
|-|-|-|
| `capability_layer.capability_mode` | `False` | **`true`** |
| `capability_layer.capability_gateway_mode` | `False` | **`true`** |
| `capability_layer.governance_audit_enabled` | `False` | **`true`** |
| `capability_layer.python_exec_enabled` | `False` (hard-wired `False`, `fail-closed`) | **`true`** |

Bounds and evidence:

- The flip was **owner-authorized**; the authorization trace is at `anima/tools/__init__.py:193`
  (see the corrected comment there).
- Upper bound of the flip: **≤ 2026-09-05 13:48** — the earliest `search.web` routing event in
  `data/governance/resolution_events.jsonl`. There is **no `config_service` audit row** for it, so
  the exact flip time is unrecoverable.
- `pilot_capability_allowlist` is still `[]`, so **`code.execute` never routed** — the pilot
  discipline claimed above **did hold** for the allowlist-gated capability.
- ⚠️ But `python.exec` was **never gated by that allowlist** — it is registered with
  `capability_only=False` (`anima/tools/__init__.py:194-195`), so "empty allowlist ⇒ nothing
  reachable" is **not** a valid inference for it. Its real gate is the four fail-closed gateway
  checks plus the provider's owner-only boundary. Measured production usage of `python.exec`:
  **0 calls** (16 resolution events, all `search.web`).
- Rollout line 67 (`NOT STARTED`) is **superseded in letter, not in substance**: the switch is
  ON, but **no pilot cohort was ever named and no governed capability has been invoked**.
