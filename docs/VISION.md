## 1. 一句话定位（权威）

> **Anima-next 是 owner 长期自用的个人 Autonomous Agent Operating System —— 非商业产品，
> 以 AGPL-3.0-only 发布，QQ 是它的第一个垂直切片。**

三条修饰语都是**边界约束**，不是宣传语：

| 约束 | 含义 | 否认的替代读法 |
|---|---|---|
| **owner 长期自用** | 单实例、单 owner、不做多租户 | 不是 SaaS / 不是平台 |
| **非商业产品** | 不做商业化、Marketplace、付费层 | 不是商业产品 |
| **AGPL-3.0-only** | 仓库 `LICENSE` 即此；公网 WebUI `/source` 提供对应源码 | **不是 MIT，不可闭源商用** |
| **QQ 是第一个垂直切片** | 内核按 runtime 设计，QQ 是首个接入 | 不只是"一个 QQ 机器人" |

代码版本：`0.3.0rc2`（`anima/__init__.py` 为唯一部署版本源）。

## 2. 三份文档各管一层（不是四套竞争愿景）

此前被读作"四套互相矛盾的愿景"。逐份看过之后，实际是**三层 + 一份过期草稿**：

| # | 文档 | 实际角色 | 状态 |
|---|---|---|---|
| **V1** | `README.md`（含 Post-R15 定位段） | **定位层**：这是什么、边界在哪、许可证 | ✅ **权威** |
| **V2** | `docs/rfc/RFC-0100*` … `RFC-0111` 系列 | **架构理论层**：一个"数字生命"由哪些层构成（本体论 / 身份 / 需求 / 情感 / 驱力 / 目标 / 计划 / 执行 / 记忆 / 反思 / 人格 / 关系） | ✅ **权威** |
| **V3** | `reports/2026-08-27_vision_gap_plan.md` | **质量锚层**：「北极星四体验」——①听懂我说的 ②记得该记的不越界 ③行动合适不烦人 ④说的『已完成』都是真的 | ✅ **权威（作为验收口径）** |
| **V4** | `design/README.md` | **过期草稿层**：Anima Console 原型说明 | ❌ **SUPERSEDED** |

三者关系：**V1 说"是什么" → V2 说"内部怎么组织" → V3 说"做到什么算好"。**
它们不冲突，冲突的是把它们都当成"最高宗旨"来读。

### 2.1 V4 为什么标 SUPERSEDED

`design/README.md` 有两处与仓库现状**直接相悖**的陈述：

1. **许可证错误**：第 50 行写 `[MIT](../../LICENSE) —— 可自由用于个人或商业项目`，
   而它链接的 `LICENSE` 文件是 **AGPL-3.0**（全文 GNU AFFERO GPL v3）。
   `README.md:7,409` 与 `AGENTS.md:57` 亦均写 `AGPL-3.0-only`。
   ⇒ 这不是"另一种路线"，是**引用了本仓库的错误许可证**。
2. **定位表述不一致**：第 3 行把它描述为"一个可自托管的 AI 伴侣 bot 框架"，
   且外链是占位 `https://github.com/`（无实际仓库）。

**处置**：该文件是 Console 前端原型的设计说明，**保留其内容作为原型文档**，
但修正许可证、并把"Anima 是什么"改为指向本文档。
**不改写 V2/V3 的历史文本** —— 它们是日期化的记录，改它们等于伪造历史。

## 3. 理论层（V2）的落地状态：**理论已冻结 ≠ 代码生效**

这是本项目最容易误读的一点，因此明确写在这里：

| 状态 | 含义 |
|---|---|
| **理论已冻结** | RFC-0100 系列文档已定稿；`docs/governance/LIFE-RFC-CLOSURE.md` 记录其闭合 |
| **代码已存在** | `anima/constitution/` 17 个模块实现了整条派生链与 Authority 边界 |
| **生产** | ⚠️ **不同** —— 见下 |

🔴 **生产实态（2026-09-18 实测）**：宪法派生链**对线上产出贡献为 0**。
两个独立原因：

1. `autonomy.drive_gate`（`config.py:140`）**代码默认 `false` 且生产未设置** ⇒
   `anima/core/autonomy.py` 的宪法 Drive 桥整条**不执行**。这是刻意的 fail-closed 设计。
2. 即使把门打开，链路本身也是断的（第一条边喂的是替身 + 下游闭环无 producer）——
   详见 `ENGINEERING_DEBT_LEDGER.md` D-01 / D-13 与
   `reports/2026-09-18_project_audit_and_evolution_plan.md` §3 落差矩阵。

⇒ **正确说法是**：*"RFC-0100 生命层是已冻结的**设计**，其实现位于
`anima/constitution/`，当前**未接入**生产行为路径（由 `drive_gate` 显式门控）。"*
**不要**说成"数字生命已实现"，也不要说成"RFC-0100 是废弃文档"。
