# Anima Console

面向 **Anima-next**（owner 长期自用的个人 Autonomous Agent Operating System，
非商业产品；见 [`docs/VISION.md`](../docs/VISION.md)）的**网页管理面板**高保真原型。

> 状态：设计原型（单文件静态 HTML，零构建）。后端尚未实现，数据均为内置示例。

## 这个面板解决什么

此前运维 Anima 只能频繁 SSH 上 VPS 查日志、重启服务、手改配置。Console 把这些操作收敛到一个可视化界面：运营管理、人格编辑、记忆浏览、插件商店、日志流，一站式搞定。

## 功能视图（原型）

| 视图 | 内容 |
|---|---|
| 仪表盘 | 服务状态 / 消息量 / 主动发言 / 记忆条目指标卡 + 自主行为配置（主动概率、沉默门控、全局冷却、@/私聊闸门）+ 链路健康度 |
| 人格设定 | 在线编辑 `persona_core.yaml`，关联认知模块（自我笔记 / 欲望 / 关系 / 世界模型 / 身份锁定 / 护栏） |
| 记忆库 | 对话 / 向量 / 自我笔记 / 世界模型 / 欲望 / 关系 六类记忆浏览 |
| 插件商店 | 接入 AstrBot 插件注册表，按兼容层适配度打标签，可触发安装 |
| 运行日志 | journalctl 风格实时流，支持错误 / 警告过滤 |
| 外观设置 | 实例名称 + 强调色换肤（跨明暗主题统一品牌色） |

## 设计原则

- **暗 / 亮双主题**，切换即时、记忆到 `localStorage`
- **玻璃拟态 + 流畅过渡 + 磁场按钮 + 呼吸状态灯**等微交互
- **可主题化**：强调色与实例名均可在「外观设置」中切换，真实部署时由后端 `config.yaml` 下发 —— 同一套面板适配任意实例，不绑定特定人格
- **开源友好**：无硬编码密钥、无个人数据；所有示例数据来自前端配置对象

## 预览

直接用浏览器打开 `anima-console.html` 即可（无需任何构建步骤）。

## 规划架构（后续实现）

```
Anima Console
├── FastAPI 后端        # 复用 bot 的 venv / 配置 / 数据目录，零额外依赖栈
│   ├── /api/config     # 读取与校验 config.yaml
│   ├── /api/persona    # 人格 CRUD
│   ├── /api/memory     # 记忆库查询
│   ├── /api/plugins    # AstrBot 插件注册表 + 安装
│   └── /api/logs       # journalctl 流式代理
└── 前端（本原型演进）   # 接入真实接口，替换内置示例数据
```

后端鉴权建议先用单一 token，后续可扩展。
