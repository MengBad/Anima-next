## 0. Executive verdict (read this first)

> **The F8.1–F8.13 governance chain has produced ZERO operational samples.
> Not because it failed, and not because it succeeded — because it was never run.**

Two independent layers each suffice to produce an empty window:

| Layer | Fact | Consequence |
|-|-|-|
| **L1 Deployment** | Production runtime does not contain `anima.capability` / `anima.runtime` / `anima.contracts` | Governance code is not importable, let alone executable |
| **L2 Activation** | Even at repo HEAD, all three sinks are `None` on every production path | Would still emit 0 samples if L1 were fixed today |

**Crucial framing correction (vs. earlier draft of this report):**
L2 is **not a defect**. It is the **ruled design state**. F8.7 Q2 chose injection
form (a) — the persistent sink is activated by externally constructing it and
attaching it to `core.governance_audit_sink`, with *production code at zero diff*.
F8.10.1 explicitly deferred evidence wiring to "F8.10.1 Implementation，另授权".
F8.12 ships `POLICIES` empty by ruling. **Nobody has ever been authorized to
activate observation.** The chain is dormant exactly as designed.

The finding of F9.1 is therefore not "the design is broken". It is:
**F9.1 could not perform its function.**

### Non-contradiction findings

| ID | Class | Finding |
|-|-|-|
| **G-01** | Activation gap | `capability_gateway_mode` is read via `getattr(cfg_layer, …, False)` but absent from `CapabilityLayerConfig`; pydantic silently drops it. Config-driven activation is impossible; programmatic activation (explicit kwarg) still works. Default-OFF invariant is *not* violated. |
| **G-02** | Deployment gap | Production predates M0.3; the entire F-series is absent. Environment fact, not a design fact. |
| **N-01** | Adjacency risk | Two unrelated subsystems both named "health": `core.health_history` (live, deployed, writing) vs `capability.health.HealthEvidence` (dormant, undeployed). No F8 document disambiguates them. |
| **N-02** | Doc precision | F8.10 §6 持久化资产盘点 marks resolution/transition as "✅ 持久化" where ✅ denotes *mechanism exists in code*, not *persistence is in effect*. Operationally all three streams are equally at zero. The asymmetry that motivated Q5 ("health evidence 无存储, therefore build one") does not exist at runtime. |

**None of G-01/G-02/N-01/N-02 qualifies as an observed contradiction under
Foundation Evolution Protocol F2.** Each is representable by the current frozen
design; none requires the design to change in order to be expressed. See the
backlog document for the adjudication.

### A design property confirmed by reading (not by runtime)

An empty observation window cannot cause a wrong governance action:

- `HealthPolicyEvaluator.decide` → `total < policy.minimum_samples` →
  `NO_ACTION` with reason `"insufficient samples: …"` (`health_policy_evaluator.py:190-198`)
- `HealthPolicy.__post_init__` enforces `minimum_samples >= 1` (`policy.py:107-111`)
- `POLICIES` ships empty ⇒ unregistered capability ⇒ `NO_ACTION` regardless

Under-observation therefore degrades to inaction, not to a false quarantine and
not to a false recovery. This closed off the one contradiction candidate that
looked promising during this survey — it was checked and it does not exist.
