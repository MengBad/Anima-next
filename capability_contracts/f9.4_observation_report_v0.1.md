## 3. Temporal Findings

### 3.1 长期稳定性（关联一致性）
- `audit_keys=20` / `health_keys=20` / `shared=20` / `audit_only=[]` / `health_only=[]`
- **`one_to_one=true`** → `execution_key ↔ ResolutionEvent ↔ HealthEvidence` 在**全部 20 个样本、跨越完整 13.666s 窗口**持续保持 1:1（非仅前几个样本）。

### 3.2 时间维度漂移
- `observed_at` 全程 **monotonic non-decreasing**（无乱序/回拨）。
- normalized_outcome 分布：`SUCCESS=10` / `FAILURE=10` —— 稳定，无新 outcome 类型。
- **UNKNOWN ratio = 0.0** —— 分类无漂移。
- 失败 pattern：唯一已知 `error_class = "工具暂时不可用，未获得可验证结果。"` —— 未出现新失败类型。
- capability 行为：`filesystem.read` 在 10 个纪元中对 ok / fail 输入始终返回一致的 transport 结果 + 正确的 normalized 结论 —— 无行为漂移。
- evidence volume：`20 ≥ 15` 阈值 → **充足支撑判断**。

### 3.3 冻结假设复验（纵向）
- `ResolutionEvent ≠ HealthEvidence`：`resolution_carries_success_field=false`、`health_carries_selection_field=false` → 字段集除共有维度 `capability_id` 外互不相交。
- `HealthEvidence ≠ LifecycleTransition`：`recovery_chain_zero=true`、`transition_file_exists=false` → 整窗 0 条 transition 记录。
- `RecoveryDecision ≠ standalone state store`：`transition_store.query()==[]`（观测期间 seam 从未被调用）→ recovery 决策未被伪装写入独立 store。
